Математическая оптимизация взвешенной модели урона и золота. Реальная эффективность, скорость и условные синергии могут отличаться. Неофициальный инструмент.

Модель расчёта и ограничения

Калькулятор оптимизирует взвешенную оценку урона и золота. Он не моделирует время престижа и не гарантирует самый сильный билд в игре.

При бюджете свыше 12 000 очков используется приближение с ограниченной погрешностью. Оптимизация внутри каждого дерева остаётся точной.

Как экспортировать данные TT2

  1. Откройте Tap Titans 2 на телефоне.
  2. В игре откройте Options → Services → Export.
  3. Скопируйте экспортированные данные игрока.
  4. Вернитесь на страницу и нажмите «Вставить из буфера» или вставьте JSON вручную.

Чтобы импортировать готовый билд в TT2, откройте Skill Tree → Saves → Import.

Используйте экспорт данных игрока или JSON сохранённого билда, но не Player API Token. Данные остаются в браузере.

Как импортировать оптимизированный билд в TT2

  1. После оптимизации нажмите «Копировать дерево TT2», чтобы скопировать готовый билд.
  2. Откройте Tap Titans 2 и перейдите к дереву навыков.
  3. Откройте Saves (сохранённые билды), выберите слот и нажмите Import.
  4. Импортируйте билд из буфера обмена, когда игра предложит это сделать.
  5. Нажмите Load to Tree, чтобы загрузить билд в дерево, и подтвердите изменения в TT2.

Используйте билд, скопированный оптимизатором, а не экспорт данных игрока из Options → Services → Export.
