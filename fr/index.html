Optimisation mathématique d'un modèle pondéré dégâts/or. Les performances réelles, la vitesse de prestige et les synergies conditionnelles peuvent différer. Outil non officiel.

Modèle de calcul et limites

Ce calculateur optimise un score pondéré de dégâts et d’or. Il ne simule pas le temps de prestige et ne garantit pas le meilleur build dans le jeu.

Au-delà de 12 000 SP, la répartition entre les arbres utilise une approximation bornée. Le calcul à l’intérieur de chaque arbre reste exact.

Comment exporter vos données TT2

  1. Ouvrez Tap Titans 2 sur votre téléphone.
  2. Dans le jeu, ouvrez Options → Services → Export.
  3. Copiez les données du joueur exportées.
  4. Revenez sur cette page et choisissez « Coller depuis le presse-papiers », ou collez le JSON manuellement.

Pour importer ensuite un build optimisé dans TT2, ouvrez Arbre de compétences → Sauvegardes → Importer.

Utilisez l'export des données du joueur ou le JSON d'un build enregistré, jamais un Player API Token. Vos données restent dans le navigateur.

Comment importer le build optimisé dans TT2

  1. Après l’optimisation, appuyez sur « Copier l’arbre TT2 » pour copier le build généré.
  2. Ouvrez Tap Titans 2 et accédez à l’arbre de compétences.
  3. Ouvrez Saves (builds sauvegardés), sélectionnez un emplacement puis choisissez Import.
  4. Importez le build présent dans le presse-papiers lorsque le jeu le propose.
  5. Choisissez Load to Tree pour charger ce build dans l’arbre, puis confirmez les modifications dans TT2.

Utilisez le build copié par l’optimiseur, et non l’export du joueur obtenu via Options → Services → Export.
