# Tactical Insight coefficient sensitivity — issue #9

The pinned Unity source describes multiplicative and additive hero-power boosts. The existing community coefficient is not a calibrated per-account hero-power model. The exact unlocked hero-power roster and scaling rules are not available in the validated import. Sources: https://tt2.wiki/en/skill-tree and https://www.tt2-compendium.com/fr//wiki/skills/tacticalinsight ; see also docs/TACTICAL_INSIGHT_LOCAL_CALIBRATION.md. Do not invent a replacement coefficient or extrapolate an uncontrolled Stats measurement.

For two fixed allocations in the same modeled context let d0 be their score difference with only the TI heuristic excluded and d1 their difference with the historical coefficient. For fraction f of that coefficient, the additive model difference is (1-f)d0 + f*d1. Its extrema on [0,1] occur at endpoints. Opposite signs imply a unique crossing f=abs(d0)/(abs(d0)+abs(d1)). Report the threshold and direction, with a numerical tie tolerance, both for current vs recommended and for the existing optional alternative vs recommended. Do not treat f as a confidence interval, an estimated real coefficient, or a recommendation to multiply the actual native hero-power bonus.

The diagnostic is available in all four languages without new controls or extra optimizer calls. The recommendation, existing alternative trigger, score formula, constraints and DP objective are unchanged. This quantifies exactly how sensitive a comparison is to the existing heuristic. The appropriate coefficient and real gameplay outcome remain unknown. Qualification: npm run check; npm run bench:22k; npm run bench:issue30; npm run test:e2e. No GitHub Actions.
