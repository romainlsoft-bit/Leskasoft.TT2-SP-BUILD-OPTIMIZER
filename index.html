How to export your TT2 data

  1. Open Tap Titans 2 on your phone.
  2. Open Options → Services → Export.
  3. Copy the exported player data.
  4. Return to this page and choose “Paste from clipboard”, or paste the JSON manually.

To import an optimized build back into TT2, open Skill Tree → Saves → Import.

Use the player data export or saved-build JSON, not a Player API Token. Your data stays in your browser.

How to import your optimized build into TT2

  1. After optimization, tap “Copy TT2 skill tree” to put the generated build on your clipboard.
  2. Open Tap Titans 2 and go to Skill Tree.
  3. Open Saves (saved builds), select a save slot and choose Import.
  4. Import the build copied to your clipboard when the game prompts you.
  5. Choose Load to Tree to apply the imported saved build; confirm the changes in TT2.

Use the optimizer’s copied skill-tree build, not the player-data export from Options → Services → Export.
